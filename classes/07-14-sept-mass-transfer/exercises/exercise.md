# In-class practice problem

Salt is transported to the world's oceans through river flow.
Water leaves through evaporation but the salt stays behind.
(In fact some processes must remove salt, because its concentration has not increased over millions of years, but the details are not clear and here we will ignore removal.)
Develop a *simple* model of this system that can be used to predict salt concetration in the oceans.

For part 1:

* Conceptual model including a sketch
* State variable(s)
* Conservation equation
* Mode and constituitive equation
* Governing equation
* Analytical solution

For part 2:

Implement your model in Python using a module approach.
If using VS Code, use best practice (see Appendix D) and try keyboard shortcuts. 

Inputs/constants, all approximate:

* Ocean volume: 1.4e9 cubic km (1.4 billion)
* River flow: 5e4 cubic km per year (50 thousand)
* Present salt concentration in oceans: 35 parts per thousand (ppt) = about 35 g/L
* River salt concentration: 0.1 - 100 mg/L but can use 10 mg/L 

You don't actually need these values, but if you successfully implement your model, why not apply it as well?
You might be curious to see how quickly the predicted salt concentration changes.
